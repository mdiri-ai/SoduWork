Each skill retains the original license and an `UPSTREAM.md` record. Adapted
packages additionally describe their changes in `ADAPTATIONS.md` or `SODUWORK.md`. Redistribution
must preserve those records and the original notices; the project MIT license
does not replace upstream terms. Upstream project names do not imply endorsement.

The public source profile declares the included directories. The third-party
manifest records reviewed license and resource hashes using UTF-8/LF so Git's
platform newline conversion cannot invalidate otherwise identical text. Other
third-party skill suites, developer account data, plugin hooks, and host display
metadata remain outside the bundle.
